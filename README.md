# ADX website

The public site for ADX (adx.in): home, privacy policy, terms of service, refund and cancellation policy, contact. Static HTML, no build step, served by GitHub Pages.

- `index.html` — home
- `privacy.html`, `terms.html`, `refund.html`, `contact.html` — the policy and contact pages
- `styles.css`, `brand/` — the DR 11 brand (wordmark, mark, tile)

Deploy: push to `main`; Pages serves the root. The custom domain is set in the repository's Pages settings once DNS for adx.in points at GitHub Pages.
